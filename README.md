🎓 Matrix Education

Matrix Education is an all-in-one learning platform built using Django.
It provides students with video lectures, infographics, related articles, AI-powered study help, and real-time news updates in one centralized platform.

🚀 Features
📘 1. Video Lectures

Students can watch subject-wise learning videos organized for easy access.

🧠 2. Infographics & Articles

Clean infographics and helpful study articles to make complex concepts easier.

🤖 3. Gemini AI Chatbot Integration

Integrated with Gemini API to let students:

Ask study-related questions

Get explanations

Clear doubts instantly

📰 4. Live News Updates

Powered by a News API so students stay updated with:

Educational news

Technology trends

Current affairs

🌐 5. Modern Django Backend

Uses Django’s MVC architecture with clean, extendable modules.

🛠️ Tech Stack

Backend: Django

Frontend: HTML, CSS, Bootstrap

AI Model: Gemini API

News Provider: News Channel API

Database: SQLite

Version Control: Git & GitHub

▶️ How to Run

Create virtual environment:

python -m venv venv
venv\Scripts\activate


Install requirements:

pip install -r requirements.txt


Run server:

python manage.py runserver


Open browser:
http://127.0.0.1:8000/
